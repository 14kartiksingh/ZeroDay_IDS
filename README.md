# ZeroDay_IDS

## Project Title
Machine Learning-Based Network Anomaly Detection for Unknown and Unseen Cyber Attacks

## Project Overview
A machine learning-based network monitoring system designed to identify known attacks and suspicious unknown traffic patterns.

## Core Components
1. Behavioral Feature Engine
2. Benign-only Autoencoder
3. Random Forest
4. Decision Engine
5. Explainable AI (XAI)
6. Clustering Engine

## Technology Stack
- Python
- FastAPI
- Scapy
- React
- Vite
- Scikit-learn
- SHAP

## Project Structure
- backend/  : Detection backend
- frontend/ : React dashboards
- models/   : Trained ML models
- dataset/  : Dataset files
- training/ : Model training scripts
- evaluation/: Testing and evaluation
- docs/     : Project documentation
